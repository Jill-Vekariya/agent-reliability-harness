WHAT THE PROJECT DOES

Small surface. Explicit boundaries.

01 / EXECUTE

Four tools. Protected SQL.

Read-only SQLite, an authorizer, query work limits, and a separate worker with a parent deadline. No shell or filesystem tool.

02 / VERIFY

Grade results with care.

Typed multiset comparison preserves duplicates. Numeric tolerance uses matching rather than a greedy shortcut. Final answers reference a complete result.

03 / REPRODUCE

Replay is a distinct mode.

Strict recordings never fall back to a model. Regression executes current tools against saved synthetic responses and fails on incompatible requests.
