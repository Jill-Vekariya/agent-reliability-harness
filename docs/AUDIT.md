# Engineering audit — 2026-10-18

Scope: harden the existing implementation on `audit/hardening-review`, starting from published `d3eb1e0`. The original clean-checkout `make ci` passed 64 tests and its 20-task synthetic gate. The baseline, 37 reference recordings, candidate YAML, and original split assignments are preserved. This audit made no live provider request, paid experiment, push, deployment, release, or permission change.

## Prioritized findings

| Priority / area | Evidence and consequence | Fix / relevant test | Verification and limit |
|---|---|---|---|
| High — spending authorization | `Ledger` used ceiling rounding for authorization as well as exposure; a sub-microdollar cap could authorize more than approved. Decimal context could round boundaries. | Floor caps, ceil exposure using integer/rational arithmetic; exact summary formatting. `test_authorized_caps_round_down_while_exposure_rounds_up`, `test_money_rounding_is_exact_even_with_low_decimal_precision`. | Fixed, locally tested; covers declared billing categories, not unknown future fees. |
| High — provider accounting | Usage parsing was outside the dispatch exception boundary. Malformed usage could leave the wrong reservation state; overrun summaries retained the old bound. | Strict usage types/ranges; unknown usage/interrupt freezes spending; known usage settles before response decoding; observed overruns remain visible. `test_provider_hardening.py`, overrun ledger test. | Fake-transport validation; actual provider/account billing compatibility remains untested. |
| High — worker lifetime | Blocking `stdin.write()` preceded the parent deadline. A worker that stopped reading could hang the parent. | Multiplex nonblocking input/output under one deadline; terminate/kill/reap cleanup. `test_deadline_includes_blocked_input_pipe`. | Verified Linux faults; process creation/host failure are outside this loop's deadline. |
| High — resumed regression | Cached attempts skipped compatibility checks, allowing a previously incompatible run to resume green. Empty suites could pass. | Recheck model payloads/errors on cached attempts; validate suite coverage, paths, identities, and reference hashes. `test_resume_cannot_turn_incompatible_attempt_into_green_gate`, empty-suite/path test. | Fixed; intentional references still need separate review. |
| High — benchmark leakage | Every current task was already public development material. Relabeling groups would not produce an unseen test set. | Record exposure history; union families with SQL-template/text-similarity components; exposed groups stay dev. `test_public_development_tasks_cannot_be_rebranded_as_holdout`. | Tooling verified; genuine held-out tasks remain zero. Public-data pretraining exposure remains possible. |
| High — incomplete experiments | Coverage inferred from observed rows could omit an entirely missing task. Interrupted orchestration lacked reliable summary checkpoints. | Declare identities before execution; checkpoint before dispatch and in `finally`; retain interrupted attempts; require complete plans for headline metrics. Missing-cohort and interrupted-campaign tests. | Validated with synthetic observations, not model evidence. |
| Medium — trace integrity | Loose nested versions/payloads and inconsistent malformed-envelope errors. Replay hashed one read and parsed another without a shared cap. | Exact version/field checks, duplicate-key rejection, contiguous indices, typed payloads, 16 MiB cap, hash/parse the same bytes; anchor cached replay. `test_recording.py`, `test_resumed_replay_remains_anchored_to_trusted_bytes`. | Fixed; self-hashes are not signatures and need a trusted reference. |
| Medium — artifact interruption | Direct JSON overwrites could leave partial traces/manifests/summaries. | Serialize first, fsync same-directory temporary, atomic replacement, cleanup. Atomic JSON interruption/nonfinite tests. | Tested; directory fsync, power-loss durability, hostile concurrent writers, and arbitrary filesystems are not guaranteed. |
| Medium — task/review contracts | Missing validation for artifact IDs, row widths, tolerance indices; no benchmark gold-review packet. | Stronger schema; blank provenance-bound assessments with dated reviewers and adjudication. Task-schema and review tests. | Tooling ready; zero actual reviews. It cannot verify identity or diligence. |
| Medium — freeze provenance | Test gate checked task/config hashes and review flags but did not bind review evidence, grouped exposure, or full experiment provenance. | Bind source/lock/task/database/split/config and approval/pricing hashes plus review/split files; validate gold, metadata, and exposure. `test_live_campaign.py`. | Temporary synthetic freeze fixtures only; no active real freeze created. |
| Medium — statistics/reporting | Pooled configurations, missing planned-only cohorts, stale Pareto files, and misleading replay/free-synthetic disclosure. | Stratify scope; count gaps and rate denominators; preserve observed-only usage/latency; clear stale outputs; distinguish playback. `test_campaign_metrics.py`. | Synthetic validation; small-family intervals and unknown cost remain limitations. |
| Medium — release/docs | Publication notes claimed an immutable Compose pin while config used a tag. Status still described an older local-only 60-test version. | Pin verified v0.2.1 index; distinguish published 64-test evidence from local audit; update status and README. | Config/historical hosted evidence checked; audit not published. |
| Reviewed — architecture/grading/CI | Four-tool boundary, typed duplicate-aware grading, target-branch PR baseline, pinned Actions, and gated release jobs already existed. | Preserve architecture and tests; add review/split validation to `make ci`. Existing grader/final-answer/viewer/export tests remain enabled. | No superficial replacement or speculative infrastructure. Audit hosted CI awaits authorized push. |
| Reviewed — interview readiness | Existing notes disclosed AI assistance and synthetic evidence but lacked the new failure cases. | Add code/test-linked explanations and ownership exercises. | Materials prepared; personal review and real model failure investigations remain user work. |

An initial targeted reproduction run returned **11 failures and 12 passes** before fixes in budget, malformed trace, and resumed/empty regression checks. This is a development observation, not 11 independent vulnerabilities or an archived benchmark. The current command capture is `reports/audit-evidence.json`.

## Adversarial verification

| Attack attempted | Expected control | Observed behavior / test | Remaining limitation |
|---|---|---|---|
| INSERT/REPLACE/UPDATE/DELETE, commented DELETE, CREATE/DROP/ALTER, ATTACH/DETACH, PRAGMA/schema/file access | Read-only URI, authorizer, approved tables, one statement | Rejected; database SHA unchanged. `test_rejects_without_modification`; valid CTE/window queries remain controls. | Finite SQL forms; reporting detector is not enforcement. |
| Recursive work, large allocation/results/cells | Progress/VM, SQLite/process limits, row/cell/output caps | Resource failure or explicitly truncated output; truncated final rejected. Sandbox/final-grade tests. | OS/SQLite differences; no hostile database/kernel guarantee. |
| Worker never reads, floods stdout, closes output but ignores SIGTERM | Multiplexed parent deadline, bounded buffer, kill escalation | Bounded failure, child reaped, private directory removed. Worker-lifecycle tests. | Trusted test-child substitution only; agent cannot select worker code. |
| Parent KeyboardInterrupt | `finally` child cleanup | Interrupt propagates after reap/directory removal. Parent-interruption test. | SIGKILL/power/host death cannot run Python cleanup. |
| Concurrent spend, insufficient cap, malformed/unknown usage, timeout/interrupt, overrun | Atomic reservation, conservative settlement, unknown freeze, request-time scope check | Caps held; unknown/overrun blocked dispatch; revocation stopped existing provider. Budget/provider tests. | No live billing certification or automatic unknown-usage refund. |
| Modified/rehashed/oversized/malformed trace, duplicate keys, wrong versions/indices, swapped task, changed cached replay | Trusted hash, bounded parsing, manifest/request/attempt provenance | Domain error or explicit rejection; no provider fallback. Recording/regression/live-resume tests. | Local self-hashes alone cannot prove authenticity. |
| Public-dev relabeling, changed reviewed gold, missing task cohort, stale measured plot | Exposure history, review snapshots, frozen provenance, planned identities, report cleanup | Invalid split/review rejected; gaps retained; headline plot/metrics suppressed. Review/campaign-metrics tests. | New families/genuine review need people; syntactic similarity misses semantic relatives. |

Finite passing tests support these controls. They do not prove complete security, prompt-injection robustness, unbiased benchmark accuracy, or production readiness.
