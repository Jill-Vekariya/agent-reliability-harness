# How this project was built

I built this project with heavy use of AI coding assistants, and I would rather say that plainly than have you guess.

## What I did

- Chose the problem and wrote the requirements: what the system had to do, what counted as evidence, and which shortcuts were not acceptable (no invented results, no deleted failures, chronological evaluation).
- Reviewed proposals and decided the trade-offs recorded in the design docs.
- Ran the experiments, demos and verification steps, and kept the results that went against the original idea.
- Published the repository, merged the pull requests and set up CI, dependency audits and secret scanning.

## What the assistant did

- Most of the initial implementation, test scaffolding and documentation drafts.
- Dependency audits and many of the regression tests that reproduce bugs before fixing them.
